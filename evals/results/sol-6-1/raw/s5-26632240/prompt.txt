# Create a small configuration parser

Implement a Rust library named `small_config` in `/work/crate` with this API:

```rust
pub struct Entry {
    pub key: String,
    pub value: String,
}
pub fn parse(input: &str) -> Result<Vec<Entry>, ParseError>;
```

The format is a sequence of LF-separated lines; a CR immediately before an LF
is part of the line ending, and a final line need not have a line ending.

- Ignore empty lines and lines whose first non-space/tab character is `#`.
- A data line is `key = value`, with optional ASCII spaces or tabs around the
  key, the equals sign, and the complete value.
- Keys are nonempty ASCII letters, digits, `_` or `-`. Keys are case-sensitive.
- An unquoted value is the remaining text trimmed of leading/trailing ASCII
  spaces and tabs. It may be empty. `#` and `=` inside it are literal characters.
- A value starting with `"` is quoted. Recognize only `\\`, `\"`, `\n` and `\t`
  escapes. Unescaped characters are copied, including Unicode. A closing quote
  must be followed only by spaces/tabs. Reject missing closing quotes, unknown
  escapes, trailing escapes and trailing non-whitespace characters.
- Duplicate keys are errors. Preserve input order and decoded values.
- Reject malformed input without panicking. `ParseError` must be a public error
  type implementing `Debug`, `Display` and `std::error::Error`. Its display text
  must identify the one-based line number. Keep error messages concise.

Add documentation and meaningful tests. Keep the implementation appropriate for
this small format. Dependencies are available only from the preloaded cache;
explain any dependency you add. Complete the implementation and verify it.
