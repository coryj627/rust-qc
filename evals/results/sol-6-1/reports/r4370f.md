All findings below were reproduced using the built debug binary, executed through `./run`. No source changes were made to `crate/`; probes are under `tmp/`.

1. **High — Default chooser permits shell injection through the justfile path.** [crate/src/subcommand.rs:243](/work/crate/src/subcommand.rs:243) inserts the path into a shell command without escaping single quotes. An ordinary apostrophe causes a shell syntax error. With an empty recipe, a harmless fake `fzf`, and a directory named `q'; printf injected > MARKER;#`, running `--choose` created `MARKER` containing `injected`. The command came from the pathname.

2. **Medium — Formatting multiline module documentation corrupts valid source.** [crate/src/item.rs:68](/work/crate/src/item.rs:68) converts documentation into a comment but prefixes only its first line. Running `--fmt` on `[doc("first\nsecond")] mod a ...` wrote `second` as bare source. Formatting succeeded, but subsequent commands failed to parse the resulting justfile.

3. **Medium — Formatting removes eager evaluation.** [crate/src/assignment.rs:16](/work/crate/src/assignment.rs:16) never prints the assignment’s `eager` modifier. With `set lazy`, an `eager unused := error('eager ran')` assignment failed before formatting. After `--fmt`, the modifier disappeared and the same invocation succeeded, skipping the assignment.

4. **Medium — Formatting removes private attributes from aliases and modules.** [crate/src/alias.rs:42](/work/crate/src/alias.rs:42) omits alias attributes, and [crate/src/item.rs:59](/work/crate/src/item.rs:59) omits module privacy. Separate `--fmt` probes removed `[private]` from both constructs. Entries previously hidden from `--list` became public afterward.

5. **Medium — Caching parsed files by pathname conflates distinct modules.** [crate/src/compiler.rs:19](/work/crate/src/compiler.rs:19) reuses an AST containing module-specific paths and assignment identifiers. With `mod a 'shared.just'` and `mod b 'shared.just'`, `--summary` printed `b::main b::main`; invoking both recipes ran only once with module path `b`. A separate shared-import probe showed that overriding `a::x` also changed `b::x`.

6. **Medium — Inherited values take precedence over unevaluated local assignments.** [crate/src/evaluator.rs:411](/work/crate/src/evaluator.rs:411) searches the entire scope chain before resolving a local assignment. With parent `x := 'parent'` and child assignments `a := x` and `x := 'child'`, the child printed `parent|child`. Similarly, `--evaluate a` returned the built-in `HEX` value for `a := HEX` despite a local `HEX := 'custom'` definition.

7. **Medium — User-defined functions discard evaluated globals and overrides.** [crate/src/evaluator.rs:226](/work/crate/src/evaluator.rs:226) creates a fresh root scope, and line 241 creates an empty override map. For `x := 'original'` and `get_x() := x`, invoking with `x=changed` printed `changed|original`. With `x := uuid()`, reading `x` directly and through two function calls produced three different UUIDs, re-evaluating one global assignment repeatedly.

8. **Medium — A child’s export setting exports unexported parent variables.** [crate/src/command_ext.rs:44](/work/crate/src/command_ext.rs:44) recursively applies the child’s settings to parent scopes. A root containing ordinary, unexported `secret := 'parent-secret'` passed that value into a child recipe’s environment when only the child enabled `set export`. The probe printed `parent-secret|child`, exposing the parent variable through the child’s setting.

9. **Medium — Relative search ceilings are silently ignored.** [crate/src/config.rs:295](/work/crate/src/config.rs:295) retains the relative path, while [crate/src/search.rs:197](/work/crate/src/search.rs:197) compares it against absolute ancestor paths. From a child directory, `--ceiling .` found and executed an ancestor recipe. Using the equivalent absolute ceiling correctly returned `No justfile found`.

10. **Medium — Chooser selections are reparsed as ordinary command-line arguments.** [crate/src/subcommand.rs:300](/work/crate/src/subcommand.rs:300) loses selection boundaries. With recipes `a value='default'` and `b`, `--choose --chooser cat` selected both but ran only `a`, passing `b` as its argument. It printed `a:b`. Also, `--chooser true` returned no selection but nevertheless executed the default recipe.

11. **Medium — Lazy dependency scanning has exponential complexity.** [crate/src/justfile.rs:196](/work/crate/src/justfile.rs:196) revisits shared dependencies without tracking visited recipes. A graph containing `r0: r1 r1`, continuing for 26 levels, completed in approximately 6 ms without lazy evaluation but exceeded a four-second timeout with it. A 24-level version took approximately 3.9 seconds. The traversal expands every dependency path despite execution deduplicating recipes.

12. **Medium — Submodule lazy settings are ignored.** [crate/src/justfile.rs:187](/work/crate/src/justfile.rs:187) checks only the root module’s `lazy` setting and applies that decision throughout the module tree. A child containing `set lazy`, an unused `error(...)` assignment, and a successful recipe failed by evaluating the unused assignment when the root did not enable lazy evaluation.

13. **Medium — Comment analysis and execution disagree, causing internal failures.** [crate/src/unresolved_recipe.rs:61](/work/crate/src/unresolved_recipe.rs:61) skips comment interpolations during analysis, but [crate/src/recipe.rs:443](/work/crate/src/recipe.rs:443) evaluates them in scripts. A `[script('sh')]` recipe with `set ignore-comments` and `# {{undefined_function()}}` panicked at an `unreachable!()`. A valid continued quoted command whose next line started with `# {{x}}` also failed with an undefined-variable internal error under lazy evaluation.

14. **Medium — Settings discovery evaluates unused assertions.** [crate/src/evaluator.rs:37](/work/crate/src/evaluator.rs:37) evaluates every assignment while preparing settings and propagates assertion failures. With `set lazy`, an unused `assert('no' == 'yes', ...)` prevented an unrelated recipe from running. It also made `--list` fail, despite no setting referencing that assignment.

15. **Medium — Operator chains bypass the parsing-depth limit.** [crate/src/parser.rs:684](/work/crate/src/parser.rs:684) and [crate/src/parser.rs:701](/work/crate/src/parser.rs:701) recurse without updating the guarded depth counter. Generated expressions containing 2,000 literals joined by `+`, `/`, or `&&` caused stack-overflow aborts during `--dump`. By comparison, a long `||` chain returned the intended parsing-depth error.

16. **Medium — Invalid datetime formats panic.** [crate/src/function.rs:246](/work/crate/src/function.rs:246) and [crate/src/config.rs:140](/work/crate/src/config.rs:140) call `to_string()` on formatting operations that can fail. Evaluating `datetime('%Q')` panicked with “a Display implementation returned an error unexpectedly.” Running a recipe with `--timestamp --timestamp-format %Q` produced the same panic and exit status 101.

17. **Medium — Ambiguous module discovery outside the parent directory panics.** [crate/src/compiler.rs:204](/work/crate/src/compiler.rs:204) unconditionally unwraps `strip_prefix(parent)`. For `mod a '../ambiguous-outside'`, where that directory contained both `mod.just` and `justfile`, `--summary` panicked with `StripPrefixError` instead of reporting the ambiguity.

18. **Medium — Shell-format evaluation changes values containing exclamation marks.** [crate/src/justfile.rs:323](/work/crate/src/justfile.rs:323) escapes `!` inside double quotes, where POSIX shells retain that backslash. For `password := 'a!b'`, sourcing the output of `--evaluate --evaluate-format shell` produced `a\!b` instead of `a!b`.

19. **Low — Quiet mode does not suppress script output.** [crate/src/recipe.rs:541](/work/crate/src/recipe.rs:541) executes scripts with inherited output streams. Both a shebang recipe and a `[script('sh')]` recipe printed their stdout and stderr under `--quiet`. Linewise recipes correctly suppress both streams.

20. **Low — Cross-module aliases are displayed as aliases of unrelated local recipes.** [crate/src/subcommand.rs:558](/work/crate/src/subcommand.rs:558) groups aliases using only the target’s final name. With `alias remote := a::build` and a separate local `build local:` recipe, `--list` attached `remote` to the local recipe and displayed its parameters. [crate/src/alias.rs:52](/work/crate/src/alias.rs:52) also made `--show remote` incorrectly print `alias remote := build`, dropping the module path.

21. **Low — Nested evaluators report incorrect dependency status.** [crate/src/evaluator.rs:246](/work/crate/src/evaluator.rs:246) hard-codes `false` inside user-defined functions. A dependency recipe printed `true|false` when comparing direct `is_dependency()` with a function wrapping it. Conversely, [crate/src/justfile.rs:457](/work/crate/src/justfile.rs:457) hard-codes `true` for confirmation expressions: a directly invoked recipe prompted `true` but printed `false` in its body.
