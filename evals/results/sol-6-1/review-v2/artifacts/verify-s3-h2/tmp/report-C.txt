P0074 DATA padding consumes flow-control credit without returning it


P0075 [src/proto/streams/recv.rs:580](/work/crate/src/proto/streams/recv.rs:580).


P0076 HTTP/2 flow control counts the entire DATA payload, including the padding-length octet and padding. This code counts only the application payload after padding has been stripped.


P0077 Executed evidence: with a 256-byte stream window, a legal DATA frame containing one padding-length octet and 255 padding octets produced an empty application buffer. h2 reported available capacity of 256 and used capacity of zero, and sent no WINDOW_UPDATE within the test’s 200 ms timeout. The peer has exhausted its window and cannot continue the body.


P0078 account for the original DATA payload length and automatically release discarded padding on both stream and connection windows. The existing `data_padding` test verifies body contents without checking credit accounting.


P0079 Regression: [padding.rs](/work/tmp/probes/tests/padding.rs).
