P0013 Processing multiple files repeats earlier content

P0014 `pulldown-cmark/src/main.rs:167`.

P0016 ```html

P0017 `read_to_string` appends to the reused buffer, which is rendered after every file.

P0018 Consequence: batch conversion duplicates content and can merge unrelated Markdown structures. Clear the buffer per file, or concatenate all inputs and render once. Add a two-file CLI regression.

P0019 CRLF becomes two spaces inside code spans

P0020 `pulldown-cmark/src/parse.rs:1340`.

P0021 Expected: CommonMark treats CRLF as one line ending, converted to one space inside a code span. Observed: input `` `a\r\nb` `` produces `<code>a  b</code>`; LF and standalone CR produce one space. The same problem occurs inside blockquotes.

P0022 Consequence: Windows-authored Markdown changes code text. Consume the complete line ending using `scan_eol`, then append one space. Extend the existing newline-in-code tests with CRLF.

P0023 A trailing tab prevents a code fence from closing

P0024 `pulldown-cmark/src/scanners.rs:528`.

P0025 Expected: CommonMark permits spaces or tabs after a closing fence. Observed: `"```\ncode\n```\t\nafter\n"` renders the closing fence and `after` inside the code block.

P0026 Consequence: an ordinary trailing tab changes the remainder of the document’s structure. Scan both spaces and tabs before checking the line ending; test both fence characters.

P0027 Case-insensitive footnote matches produce broken HTML links

P0028 Locations: `pulldown-cmark/src/html.rs:53`, `:139`; related reference emission: `pulldown-cmark/src/parse.rs:768`.

P0029 Expected: references accepted as matching the same definition share its destination and number. Observed:

P0030 ```markdown
ref [^FOO] [^foo]

[^foo]: Note
```

P0031 produces references to `#FOO` numbered 1 and `#foo` numbered 2, while only `id="foo"` exists. Unicode case-folding variants also receive separate numbers and unmatched destinations.

P0032 Consequence: accepted footnote references fail to navigate and display inconsistent numbering. Resolve references to a canonical definition identifier and use the same case-folded identity for numbering. Add ASCII and Unicode case-variant tests.

P0033 HTML I/O rendering silently truncates output on successful short writes. pulldown-cmark/src/html.rs:595. Passing a conforming std::io::Write implementation that accepts only two bytes per write to html::write_html_io loses the unwritten suffixes of tags and text. The streaming rendering path treats each successful write as completion of the whole fragment instead of retrying the remaining bytes. Rendering an ordered list such as "3. café & tea" can therefore return Ok while producing incomplete HTML.

P0034 Standalone CR line endings are inconsistently recognized

P0035 `pulldown-cmark/src/scanners.rs:508`.

P0036 Expected: CommonMark accepts LF, CRLF, and standalone CR. Observed: `scan_nextline` searches only for LF. With heading attributes enabled, `"# heading\r\rpara\r"` becomes one heading containing the following paragraph. Executed probes also found incorrect fenced-code, indented-code, and HTML-block behavior with CR-only input.

P0037 Consequence: valid documents can acquire substantially different block structure. Make line scanning recognize all documented endings and verify affected block consumers with equivalent fixtures.

P0038 Link-label length counts non-ASCII bytes and ignores ordinary ASCII

P0039 `pulldown-cmark/src/linklabel.rs:122`.

P0040 Expected: labels contain at most 999 Unicode characters. Observed boundary probes:

P0041 - 499 `é` characters resolve; 500 do not.
- 249 crab emoji resolve; 250 do not.
- 1,000 ASCII `a` characters still resolve.

P0042 The counter increments for every non-ASCII byte and does not increment for ordinary ASCII letters.

P0043 Consequence: valid internationalized reference labels are rejected, while over-limit ASCII labels are accepted. Count Unicode characters consistently, including escaped and whitespace portions. Add boundary tests for several UTF-8 widths.

P0044 Wikilink source ranges omit the final bracket

P0045 `pulldown-cmark/src/parse.rs:944`.

P0046 Expected: `OffsetIter` returns the corresponding complete source range. Observed: `[[Wiki]]` produces link start/end ranges `0..7`, although the construct occupies `0..8`. Embedded wikilink images have the same off-by-one error.

P0047 Consequence: editors and source transformations leave a bracket behind or select incomplete syntax. Use the end of the second closing delimiter and assert complete ranges for links and images.

P0048 Empty wikilink aliases render delimiter text

P0049 `pulldown-cmark/src/parse.rs:900`.

P0050 Expected: closing delimiters remain syntax when handling an empty display label. Observed: `[[Wiki|]]` renders:

P0051 ```html
<p><a href="Wiki">]]</a></p>

P0052 The selected child starts at a closing-bracket node.

P0053 Consequence: boundary-case input generates visibly incorrect link text. Handle an empty alias explicitly—either according to a documented empty-label behavior or as literal Markdown—and keep delimiter nodes outside its children.

P0054 Single-character heading attributes are silently dropped

P0055 `pulldown-cmark/src/firstpass.rs:2548`.

P0056 Expected: documented custom attributes without values are retained regardless of name length. Observed: with heading attributes enabled, `# heading {x}` renders `<h1>heading</h1>`, losing `x`; longer attribute names work.

P0057 Consequence: callers lose attributes from both parsed events and rendered HTML. Apply the length restriction only to prefixed ID/class forms, and test one-character custom attributes.

P0058 Literal NUL is retained instead of replaced

P0059 `pulldown-cmark/src/firstpass.rs:2355`.

P0060 Expected: the bundled CommonMark contract requires U+0000 to become U+FFFD. Observed: ordinary input `"a\0b"` renders `"<p>a\0b</p>\n"`.

P0061 Consequence: output text contradicts the claimed CommonMark normalization. Normalize literal NUL while preserving source offsets, and add event and renderer regressions. This was checked solely as a correctness case; no security impact was investigated.

P0062 SIMD unchecked-access contracts are incomplete
