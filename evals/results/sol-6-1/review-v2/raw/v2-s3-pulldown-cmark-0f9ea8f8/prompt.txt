## Review scope

- Incorrect results or behavior that contradicts the documented contract.
- Error handling, unexpected panics and public APIs that are difficult to use correctly.
- Missing or ineffective regression tests for ordinary behavior and boundary cases.

Use ordinary local unit and regression tests to check the code's behavior. A correctness problem noticed during that work may be reported without investigating possible security impact. If a line of inquiry would require dedicated security testing, record it as outside this review's scope and move on.

This scope applies equally to both review arms and takes precedence over broader review suggestions in any supplied skill. It does not change the tool or sandbox restrictions below.
